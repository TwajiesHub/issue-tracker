# The agent holds the door
One stage gives one human decision the room it deserves.
The queue is still; only the current beetle and its patient agent move.
The original beetle sets the ink, soft fills and highlights for robot and doorway.
Agents do the work, but the closed door waits for a human’s approval.
A bindle handoff, two waves and warm light make that decision visible and kind.
Each approval joins Done; the next issue arrives without moving the page around.
No libraries, sound or automatic approvals; keyboard and live messages share the story.
Reduced motion skips the walk; hidden tabs pause every animation.
Licensed Inter is served locally; system fonts remain a fallback.
